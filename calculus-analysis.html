Calculus: In Depth Analysis

Limits, derivatives, integrals, and applications

Introduction

Calculus studies how quantities change (differential calculus) and how quantities accumulate (integral calculus). Developed independently by Newton and Leibniz in the 17th century, calculus builds on limits, formalizes instantaneous change, and provides tools for modeling and solving real-world problems across science and engineering.

This in-depth analysis expands intuition with rigorous definitions, proofs sketches, a broad set of worked examples, numerical concerns, pedagogical notes, and pointers to advanced study.

Rigorous Foundations: Limits, Continuity, and ε–δ

Limit (ε–δ): We say lim_{x→c} f(x) = L if for every ε > 0 there exists δ > 0 such that 0 < |x - c| < δ implies |f(x) - L| < ε. This formalism allows precise proofs of limit laws and continuity.

Continuity: f is continuous at c if lim_{x→c} f(x) = f(c). Continuous functions on closed intervals are bounded and achieve extrema (Extreme Value Theorem); they also satisfy the Intermediate Value Theorem.

Practice: prove that polynomials are continuous using ε–δ or composition rules; use limit laws to combine simpler limits into complex ones.

Differentiation — Theory and Practice

Definition

The derivative at x is f'(x) = lim_{h→0} (f(x+h)-f(x))/h when that limit exists. Existence implies local linear approximation: f(x+h) ≈ f(x) + f'(x)h for small h.

Rule Proof Sketches

Product rule: derive from limit definition: (fg)' = lim (f(x+h)g(x+h)-f(x)g(x))/h = f' g + f g'.

Chain rule: If y=f(u) and u=g(x) then dy/dx = (df/du)(du/dx). Proof uses substitution and limit manipulation; it's essential for composition of functions.

Mean Value Theorem & Taylor's Theorem

Mean Value Theorem: if f is continuous on [a,b] and differentiable on (a,b), there exists c in (a,b) with f'(c) = (f(b)-f(a))/(b-a). Taylor's theorem gives polynomial approximations with explicit remainder terms that quantify approximation error.

Worked derivative example: f(x)=x^3 - 3x^2 + 2x. Compute f'(x)=3x^2 - 6x + 2, find critical points and classify using second derivative f''(x)=6x - 6.

Integration — Definitions & Techniques

The Riemann integral defines ∫_a^b f as the limit of Riemann sums. Proper understanding requires partitions, upper/lower sums, and criteria when the limit exists. Improper integrals extend this to unbounded intervals or integrands with singularities; convergence tests (p-test, comparison) determine existence.

Techniques and Examples

  • Substitution (u-sub): change variables to invert the chain rule.
  • Integration by parts: ∫ u dv = uv - ∫ v du (useful when product of functions present).
  • Partial fractions: decompose rational functions into elementary fractions.
  • Improper integrals: analyze convergence via comparison or limit-based definitions.

Worked integral example (u-sub): ∫ x cos(x^2) dx. Let u = x^2, du = 2x dx → integral becomes 1/2 ∫ cos(u) du = 1/2 sin(u) + C = 1/2 sin(x^2) + C.

Improper integral example: ∫_1^∞ 1/x^p dx converges iff p > 1. Proof uses antiderivative and limit as upper bound → ∞.

Sequences, Series, and Power Series

Series ∑ a_n require convergence tests: comparison, ratio, root, integral, and alternating series tests. Power series ∑ c_n (x-a)^n have radius of convergence R found via the ratio/root test. Within R they converge uniformly on compact subsets and can be differentiated/integrated term-by-term.

Taylor series example: e^x = ∑_{n=0}^∞ x^n/n!, radius R = ∞. Taylor polynomials approximate functions with remainder term given by Lagrange form.

Multivariable & Vector Calculus (Expanded)

Partial derivatives, gradients, directional derivatives, and the Jacobian matrix generalize single-variable derivatives. Critical point classification uses the Hessian matrix. Multiple integrals require iterated integration or coordinate transforms (polar, cylindrical, spherical) with Jacobian determinants.

Vector calculus introduces line integrals, work, flux, and fundamental theorems: Green's theorem (plane), Stokes' theorem (surface), and Divergence theorem (volume) — each relating integrals over boundaries to integrals of derivatives inside.

Differential Equations & Modeling (Expanded)

Linear ODEs with constant coefficients, method of undetermined coefficients, variation of parameters, and systems (matrix exponentials) are core. Stability analysis (eigenvalues, phase portraits) classifies long-term behavior. PDEs (heat, wave, Laplace) introduce boundary-value problems and separation of variables.

Numerical solvers (Euler, RK methods, multistep methods) provide controlled error and stability properties; stiffness requires implicit methods (Backward Euler, implicit RK).

Numerical Methods & Practical Issues

Numerical differentiation is ill-conditioned (amplifies noise). For integration use adaptive quadrature, Simpson's rule, or Gaussian quadrature for high accuracy. Error analysis (truncation, roundoff) and algorithm stability determine suitability for real-world computation.

Implementations: use libraries (SciPy, NumPy) for robust routines; understand limitations on step size, floating-point precision, and algorithmic complexity.

Pedagogy, Exercises, and Teaching Tips

Recommend sequence: limits & continuity → derivatives (rules, MVT) → applications (optimization, motion) → integrals & FTC → series → multivariable → ODEs. Blend conceptual tasks (graphical interpretation) with symbolic practice and computational experiments.

Use visual tools (slope fields, dynamic area accumulation), assign short proof tasks (ε–δ, MVT), and scaffold technique practice (u-sub, by parts) with immediate feedback.

Suggested Exercises

  1. Prove using ε–δ that lim_{x→2} 3x+1 = 7.
  2. Differentiate and classify critical points for f(x)=x^4 - 4x^3 + 6x^2.
  3. Evaluate ∫_0^∞ e^{-x} dx and discuss convergence.
  4. Find Taylor polynomial of degree 3 for ln(1+x) about x=0 and estimate remainder for |x|<0.5.
  5. Solve dy/dx + 2y = e^{-x} with initial condition y(0)=1 (linear ODE).

Worked Examples — Detailed Solutions

1) Derivative with Product & Chain Rules

Let f(x) = x^2 · sin(x^3). Then f'(x) = 2x·sin(x^3) + x^2·cos(x^3)·(3x^2) by product and chain rules. Simplify:

f'(x) = 2x sin(x^3) + 3x^4 cos(x^3).

2) Optimization (Critical Points & Second Derivative Test)

Find extrema of g(x)=x^3 - 3x^2 + 2x. Compute g'(x)=3x^2 - 6x + 2. Solve 3x^2 - 6x + 2 = 0 → x = (6 ± √(36 - 24))/6 = (6 ± √12)/6 = 1 ± √3/3.

Second derivative g''(x)=6x - 6. Evaluate at the critical points to classify: at x = 1 + √3/3, g'' > 0 (local min); at x = 1 - √3/3, g'' < 0 (local max).

3) Improper Integral by Parts

Evaluate ∫_0^∞ x e^{-x} dx. Use integration by parts with u=x, dv=e^{-x}dx → du=dx, v=-e^{-x}.

Then ∫_0^R x e^{-x} dx = [-x e^{-x}]_0^R + ∫_0^R e^{-x} dx = (1 - (R+1)e^{-R}). Taking R→∞ gives 1.

4) Taylor Approximation (ln(1+x))

ln(1+x) = x - x^2/2 + x^3/3 + O(x^4). For x=0.2, third-degree approximation gives 0.2 - 0.02 + 0.002667 = 0.182667 (true ln(1.2) ≈ 0.182322), error ≈ 3.45e-4.

5) Multivariable — Gradient & Hessian

Let h(x,y)=x^2 + x y + y^2. Gradient ∇h = (2x + y, x + 2y). Solve ∇h=0 → x=y=0 (single critical point). Hessian H = [[2,1],[1,2]] with eigenvalues 3 and 1 (both >0) so (0,0) is a local minimum.

6) First-order Linear ODE (Integrating Factor)

Solve y' + 2y = e^{-x}, y(0)=1. Integrating factor μ(x)=e^{∫2 dx}=e^{2x}. Multiply: (e^{2x}y)' = e^{2x}e^{-x}=e^{x}. Integrate: e^{2x}y = ∫ e^{x} dx = e^{x} + C. So y = e^{-x} + C e^{-2x}. Use y(0)=1 → 1 = 1 + C → C=0. Thus y = e^{-x}.
