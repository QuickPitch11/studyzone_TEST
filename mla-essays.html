MLA Essays — Overview

A concise overview of MLA essay formatting and structure. Click "In-Depth" for the complete guide.

What this page is

This is the brief overview page for MLA Essays. For the full, exhaustive MLA 9 guide (formatting, citations, Works Cited, parenthetical references, and checklist), use the "In-Depth" link below which opens the detailed analysis page.

Key Points

  • • Use MLA 9th edition unless instructed otherwise
  • • 1-inch margins, double-spaced throughout, Times New Roman 12pt font
  • • Header: Last name and page number (top-right corner)
  • • First page: Name, instructor, course, date (day month year format), then centered title
  • • In-text citations use author-page format: (Smith 45)
  • • Works Cited page: separate page, centered title, hanging indent for entries

Basic In-Text Citation

Signal phrase with author name:

According to Smith, "quotation here" (45).

Parenthetical citation:

"Quotation here" (Smith 45).

No author (use title):

("Article Title" 12).

Works Cited Format (Common Sources)

Book:

Last Name, First Name. Book Title. Publisher, Year.

Journal Article:

Last Name, First Name. "Article Title." Journal Name, vol. #, no. #, Year, pp. ##-##.

Website:

Last Name, First Name. "Page Title." Website Name, Publisher, Date, URL.

Header and First Page Setup

Top-right header (every page):

Smith 1

First page heading (left-aligned, double-spaced):

John Smith

Professor Johnson

English 101

15 January 2026

Title (centered):

The Symbolism in Shakespeare's Macbeth

Quick Checklist

  • ✓ Double-spaced throughout (no extra spaces between paragraphs)
  • ✓ 1-inch margins on all sides
  • ✓ Times New Roman 12pt font (or similar readable font)
  • ✓ Last name + page number in header (top-right)
  • ✓ No title page (unless specifically requested)
  • ✓ Title centered, not bold/underlined/italicized
  • ✓ Indent first line of each paragraph (0.5 inch or Tab)
  • ✓ Works Cited on new page, centered title, alphabetical order
  • ✓ Hanging indent for Works Cited entries (0.5 inch)

Common Mistakes to Avoid

  • ✗ Using incorrect date format (use: 15 January 2026, not January 15, 2026)
  • ✗ Forgetting page numbers in citations
  • ✗ Using bold, italics, or quotation marks for your essay title
  • ✗ Not alphabetizing Works Cited entries
  • ✗ Single-spacing anywhere in the document
