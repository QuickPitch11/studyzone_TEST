## Randomization System Features

Each quiz now includes:

1. **40-Question Bank**: Comprehensive questions covering all major topics
2. **15 Random Questions**: Each quiz attempt shows 15 randomly selected questions
3. **Answer Shuffling**: The 5 answer options are shuffled for each question
4. **Instant Feedback**: Correct/incorrect feedback with detailed explanations
5. **Percentage Scoring**: Shows score as percentage with color-coded feedback
6. **Responsive Design**: Works on desktop, tablet, and mobile
7. **Professional Styling**: Tailwind CSS with subject-specific color themes

## Technical Implementation

### JavaScript Features:
- **Fisher-Yates Shuffle Algorithm**: Ensures true randomization
- **Dynamic HTML Generation**: Questions generated on page load
- **Answer Tracking**: Maintains correct answer indices after shuffling
- **Score Calculation**: Automatic grading with detailed review

### Question Format:
```javascript
{
  question: "Question text here?",
  options: ["Option 1", "Option 2", "Option 3", "Option 4", "Option 5"],
  correct: 0, // Index of correct answer (0-4)
  explanation: "Detailed 2-4 sentence explanation."
}
```
